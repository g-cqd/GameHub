# 2026-10-11 (01): Data store, runtime app, BF3 fullscreen, and DXMT robustness

*Reconstructed on 2026-10-31 from the commit history of the five repositories; nothing here was re-run.*


- **The data store and runtime are configurable** (ADR-0002). The data store is moved by a journalled manifest that
  only renames on the same drive. The runtime is installed as an app and verified file by file. The shared prefix is
  located safely and refused when its drive is unplugged.
- **Onboarding:** a bounded PE scanner and folder markers.
- **Battlefield 3:** runs full screen only, with the display size written into its settings at every start.
- **winemac:** emulated display modes, native full screen for covering windows, and a black full-screen space where
  the program draws nothing.
- **DXMT:**
  - draws and dispatches whose pipeline failed to compile are dropped;
  - compiles that lost the compiler service are retried;
  - rename copies are bounded on 32-bit;
  - back-buffer RTVs use a hidden texture.
- **Wine:** the sidecar's `ROSETTA_DISABLE_AOT` is no longer passed to child processes (ADR-0007), and the macOS font
  list is cached for the wineserver session.
- **x87sidecar:** an x87 instruction is handed to stock when stock's cached XMM scalars leave too few scratch FPRs.
