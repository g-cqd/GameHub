# 2026-10-13 (01): Raw Windows syscalls for the EA anti-cheat

*Reconstructed on 2026-10-31 from the commit history of the five repositories; nothing here was re-run.*


Wine now emulates raw Windows syscalls executed by native code on macOS. The table is resolved before guest code can
patch the stubs and indexed one past the encoded value. Windows 19045 `Zw` stubs are presented to the EAAC loader,
and `wine_get_version` is renamed. Tests cover the syscall flag semantics. This is the EAAC line of ADR-0014.
