This directory contains one-off scripts and patch helpers from the 2026-10 ARM64 Wine/EAAC integration effort.

These scripts must not be run. They are kept as a record of the 2026-10 workflow.

Python patch utilities and message files are supporting scripts that were part of the 2026-10 mtld3d work. Some scratch material from this period may have been rescued to `../work-archive/` (see that directory if present).
